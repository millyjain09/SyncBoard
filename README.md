# SyncBoard

SyncBoard is a collaborative project management and real-time workspace platform designed to streamline team workflows, task tracking, and organizational coordination.

---

## Tech Stack

* **Frontend:** React.js / TypeScript, Tailwind CSS *(update based on `frontend/package.json`)*
* **Backend:** Node.js, Express.js
* **Database:** PostgreSQL / MongoDB *(update based on your DB setup)*
* **Real-Time Communication:** Socket.io
* **Authentication & Security:** JWT / Role-Based Access Control (RBAC)
